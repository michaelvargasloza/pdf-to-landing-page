# Changelog

Todos los cambios notables en este proyecto seran documentados en este archivo.

El formato esta basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/),
y este proyecto se adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-26

### Added
- Extraccion y estructuracion de contenido desde documentos PDF a formato Markdown mediante PDF.js y Web Worker.
- Diseno y generacion automatica de Landing Pages mediante Google Gemini AI.
- Visor de previsualizacion responsiva con soporte interactivo para modos escritorio, tablet y movil.
- Modo de edicion visual interactiva para personalizar textos directamente en la previsualizacion.
- Panel de personalizacion de diseno para ajuste dinamico de colores principales, fondos y radios de borde.
- Editor integrado de codigo HTML/CSS y visualizador de Markdown extraido.
- Herramienta para descarga y exportacion de paquetes web HTML autoejecutables.
- Arquitectura modular construida en Angular 18 con componentes standalone desacoplados y modelos estrictamente tipados.
